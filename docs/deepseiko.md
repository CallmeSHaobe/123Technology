# 大肥鱼（DeepSeiko）——双模式巨型多方块

> 本文介绍本次 PR 新增的主要内容：**机器「大肥鱼 / DeepSeiko」及其配套**（结构方块、物品、配方、GUI、全息投影），
> 以及附带的一个 **CropsNH 水稻作物**。
>
> 代码入口：`com.newmaa.othtech.machine.OTEDeepSeiko`；配方：`com.newmaa.othtech.recipe.RecipesDeepSeiko`。

---

## 一、这是什么

一台 **60×23×33（2,784 格）的鲸形多方块**，两种运行模式：

| 模式 | 定位 | 核心机制 |
|---|---|---|
| **装配线（AL）** | 通用大型装配 | 无损超频、无限并行、**不需要数据棒/闪存**；加速只由结构方块（时间环 × 稳定环）决定 |
| **凝聚态（BEC）** | 后期凝聚态量产 | 沿用 TecTech 的「点数」模型，但**只要求配方原流体**；速度由三环 × 算力卡 × 升级进度决定 |

机器成型后，控制器正面会悬浮一个**自发光米饭碗全息投影**（满 → 吃空 → 再添满循环），作为运行状态指示。

---

## 二、结构与三环

- 尺寸 `60×23×33`，方块分布：鲸脂外壳 977 / 装配腔 909 / 腹褶 473 / 三鳍 236 / 鲸须 75 / 舱位 59 / 其他 55；
- 控制器在吻部尖端中心（结构 y=12）；
- 头部一圈 40 格标准舱位：输入/输出总线、输入/输出仓、能源/激光仓；
- **三条鳍信道**（左鳍=时间 / 右鳍=空间 / 顶鳍=稳定），每条 1~10 级：1 级 = 鳍方块，2~10 = 对应场发生器；
  同一信道必须同级。

三环效果：

| 信道 | 每级 | 满级（9 级生效） |
|---|---|---|
| 时间 | +5% 速度 | ×1.50 |
| 空间 | -5% 耗电 | ×0.50 |
| 稳定 | +2.5% 速度 / -2.5% 耗电 | ×1.20 / ×0.80 |

**并行**：三环已装等级取平均 → `512 × 8^(L-1)`，L9 为 `Integer.MAX_VALUE`（无限并行）。
BEC 的批量时长里并行按 `min(N, 65,536)` 计，超过只加数量、不再缩短时长。

## 三、BEC 点数模型

```
P/tick = 基础 × 时间环 × 稳定环 × 算力卡系数 × 升级乘区
单件时长 = P ÷ (P/tick) ÷ 20 秒（未终极最少 1 秒；终极解锁后地板降到 0.2 秒）
批量时长 = 单件 × N^(1-α)      α = 0.70（终极前） / 0.85（终极后）
```

- 基础：未终极 21,340 点/t；终极 500,000 点/t；
- 升级乘区：0 升级 75% → 三项全满 100%（BEC 解锁 / 蜂群 10 级 / 终极）；
- 算力卡：`倍率 = 1 + ³√(张数) × 卡系数`。
  | 卡片 | 系数 |
  |---|---|
  | D999 / D199 / D99 | 0.25 / 0.16 / 0.08 |
  | 普朗克电路 | 0.10 |
  | 量子电路 | 0.05 |
  | 皮米电路 | 0.025 |
  | 690 战术核显卡 / 银色调试币 | 0.0123 |
  | 金色调试币 | 特殊：直接满算力（×10,000 上限） |

- 蜂群门槛：配方要求「机体升级的纳米蜂群等级 ≥ N」，N 由配方的 `NANITE_TIERS` 元数据决定。

## 四、升级与机体

| 升级 | 消耗 | 效果 |
|---|---|---|
| 凝聚态解锁 | 4× 凝聚态适配舱 | 解锁 BEC 模式 |
| 纳米蜂群 | 每级 64 个对应纳米蜂 | 提高可跑的配方等级（1~10） |
| 终极解锁 | 见升级面板 | 基础推进 300k→500k、并行指数 0.70→0.85、单件地板 1s→0.2s |

另有**纳米蜂收容仓**：可插一颗纳米蜂作为「外部蜂群输入」，与升级面板的等级取较高者。

## 六、物品与方块

- **方块**：12 个 meta 的 `dsCasing`（0~8 机壳、9/10/11 三鳍），另有不可见的全息影子方块 `dsHoloRice`；
- **物品**：白米饭、馊米饭、金色/银色调试币、D99/D199/D999 算力中心、米饭奇点、时空冷却核心、纳米蜂收容仓；
- **贴图**：机壳 9 张、控制器正/侧面、GUI 面板与金币动画 8 帧、米饭/碗模型贴图、算力中心与物品图标。

---

## 七、GUI 与全息

- MUI2：主控制台（运行状态、进度、点数、处理速度、模式切换按钮、头像气泡）；
- 左「加速」侧栏：总倍率、算力、加速、耗电、推进、三环等级；
- 右「升级」侧栏：三项升级状态、打开升级面板按钮；
- 两侧底部各有一个同步旋转的调试币动画（未插卡时压暗，插卡后点亮）；
- 两个侧栏与升级覆盖层均为**固定面板**（不可拖动）；
- 全息投影：控制器正面 6 格、低 3 格，放大 2 倍、自发光（不受昼夜/光照影响）。

## 八、CropsNH 水稻（附带）

- 作物 id `cropsnh:rice`，tier 1，800 tick，产出矿辞 `cropRice`（100%）；
- 种子来源：`seedRice`（无序合成）→ 水稻种子（已分析，Growth/Gain/Resistance 1）；
- 注册方式：`MixinCropLoader` 注入 CropsNH 的 `CropLoader.postInit()` 末尾，
  这样种子生成器 / 合成器 / 基因提取等 GT 配方都会自动生成；
- 兼容：`after:cropsnh` 软依赖 + 独立 `mixins.othtech.cropsnh.json`（`required:false`），
  **没装 CropsNH 时只跳过该作物**，不影响其它功能。
